AI-Enabled Development

Mobitru

Project Manager · Architect · AI Advocate — ongoing
Problem
A mature mobile and cross-browser testing platform, years on the market and inherited from a previous owner, had to stay relevant as AI assistants started doing work engineers used to do by hand.
Approach
Drove the platform's shift to an AI-native product: introduced a Mobile MCP Server and a Playwright MCP Server so AI assistants operate test infrastructure directly, authored Claude Code Skills on top, and folded in BrowserKube — my own open-source project — to add desktop browser testing.
Outcome
A years-old product repositioned as AI-native testing infrastructure: established platform, open-source extension, and AI-assistant-facing layer, working as one system.

Platform & Infrastructure Engineering

SKAEL

Founding Golang Engineer → Solution Architect
Problem
Building a hyper-automation platform — an automation engine plus a RASA-based conversational layer — for enterprise clients, deployable as SaaS or hybrid SaaS+on-prem. RASA itself had no multitenancy story.
Approach
Joined pre-product, working directly with the founders (later the company's C-suite) from idea through architecture through build. Built the automation core on Temporal for durable, fault-tolerant workflow execution, and wrote a custom Golang Operator to run isolated RASA instances per tenant.
Outcome
"Digital employees" before the term existed — a platform that carried the company through multiple funding rounds.

About

Engineer, architect, brevet rider

I'm a software engineer and architect based in Warsaw, Poland — originally from Minsk, Belarus, with a degree in Electronics from BNTU. Over more than a decade in the industry, I've kept circling back to the same kind of work: taking something from "someone's idea" to "a platform that actually runs in production" — usually for startups, almost always with open source somewhere in the foundation.

I like moving fast without cutting corners that come back to bite you later — durable-execution engines instead of duct tape, multitenancy designed in instead of bolted on, infrastructure that's boring in the right ways. Lately that also means bringing AI into the loop properly: not as a demo, but as something a platform is actually built around.

Outside of work: family, a daughter, a dog, and long-distance cycling — brevets, mostly, which is its own lesson in pacing yourself for the long haul.
